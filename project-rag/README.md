# RAG do site Crispim & Campos

Contexto local enxuto para agentes que trabalham no repositório conhecido como `lele-site`.

## Roteamento por tarefa

- Estado atual, pendências e riscos: `memory/current-state.md`
- Arquitetura, integrações e mapa de arquivos: `context/architecture.md`
- Produto, marca e limites editoriais: `context/product.md`
- Trabalho incompleto e retomada: `memory/handoff.md`

Leia apenas os documentos necessários e confirme tudo no código antes de implementar.

## Atualização da memória

- Mudança de arquitetura, integração ou caminho: atualize `context/architecture.md`.
- Mudança de conteúdo, público ou identidade: atualize `context/product.md`.
- Mudança de estado, risco ou próxima prioridade: atualize `memory/current-state.md`.
- Entrega interrompida: atualize `memory/handoff.md`.

Não copie dados pessoais, credenciais, sessões, conteúdo real de processos ou exports do Supabase para esta pasta.
